Time Your Sheet

A VS Code extension that keeps a flextime balance from the Markdown note you already write in all day.

You're assumed to be working during work hours, so you only log the exceptions: stepping out, coming back, starting early, staying late. The extension reads those lines and keeps a running debt or advance in the status bar. A normal day needs no lines at all. 

#### 2026-10-02
- [x] review PR #482
14:54:09 out
15:32:04 in
18:05:12 out
adjust -30m slow afternoon

Your note stays the database: no server, no account, no separate file. One shortcut toggles in and out.
